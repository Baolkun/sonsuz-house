# Sonsuz House

Odada arka planda açık kalacak, kendi kendine bestelenen, hiç tekrar etmeyen sakin house müziği.
Her ses tarayıcıda Web Audio ile o anda üretilir; kayıt ya da örnek dosya yoktur.

Canlı: https://baolkun.github.io/sonsuz-house/

Yerelde denemek için: `python3 serve.py` ve http://localhost:8790
